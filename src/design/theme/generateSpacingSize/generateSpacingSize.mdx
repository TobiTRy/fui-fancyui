## Spacing Size Utility

A TypeScript utility function for calculating spacing values dynamically, supporting optional `px` suffix formatting.

## Setup

```tsx
import { generateSpacingSize } from 'fui-fancyui';
```

## Function

### `generateSpacingSize`

Calculates a spacing value based on a step number, returning either a number or a string with a `'px'` suffix.

#### Parameters

| Name     | Type    | Default | Required | Description                                              |
| -------- | ------- | ------- | -------- | -------------------------------------------------------- |
| `step`   | number  | -       | ✅       | The step number in the spacing scale (positive integer). |
| `withPx` | boolean | `false` | ❌       | Whether to return the value as a string with `'px'`.     |

#### Returns

- `number | string` - The calculated spacing value, either as a number or a string with `'px'`.

#### Example Usage

```tsx
const spacing = generateSpacingSize(3); // Returns 8
console.log(spacing);

const spacingWithPx = generateSpacingSize(3, true); // Returns '8px'
console.log(spacingWithPx);
```

#### Notes

- **Step Calculation Pattern**:
  - Step `1` → `2px`
  - Step `2` → `4px`
  - Step `3` → `8px`
  - Step `4` → `16px`
  - Steps `5-6` → Adds `8px` per step
  - Steps `7+` → Adds `16px` per step
- The function throws an error if `step` is not a positive integer.
